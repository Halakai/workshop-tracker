Workshop Tracker: privacy

Workshop Tracker is a private tool used by the members of one small car workshop to keep track of their parts stock, cars, small repair jobs and shared money. There is no public sign-up. Only people the workshop’s admin creates an account for can use it.

What is stored

  • Members’ names, email addresses and passwords (passwords are handled by Supabase Auth and never stored in plain text).
  • The workshop’s records: parts, cars, jobs, customers’ names and phone numbers, and money entries.
  • Photos and receipts that members upload.

Where it is stored

  • Records are stored in a Supabase database (EU region) and protected so that only signed-in members can read them.
  • Photos and receipts are stored in the workshop admin’s own Google Drive, in a folder named “Workshop Tracker”. The app uses Google’s drive.file permission, so it can only see and manage files it created itself. It cannot read anything else in that Google Drive.

Sharing

Nothing is sold or shared with anyone. The data is used only to run the workshop. There is no advertising and no tracking.

Deleting data

Members can delete entries in the app. The admin can disable accounts and export or delete all data. Access to Google Drive can be revoked at any time in the Google account’s security settings (Third-party apps & services).

Contact

Questions about this app go to the workshop’s admin.
